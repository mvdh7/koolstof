# Version history

## Version 1

### v1.0.1 (8 July 2026)

!!! info "v1.0.1 release notes"

    * Removed obsolete kwargs in several functions.
    * Fixed crash when logfile ended with incomplete dataset for a sample.

### v1.0.0 (18 May 2026)

!!! info "v1.0.0 release notes"

    * Package simplified to include coulometric DIC processing tools only.
    * Blank correction approach documented by [Humphreys and Ossebaar (2025)](https://doi.org/10.5194/os-21-3123-2025).  Any changes to the code between v1.0.0b3 described in that manuscript and the v1.0.0 release are negligible.
